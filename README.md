# accessmonitor-docker
AccessMonitor Docker

**Nota 20/05/2026** - para além do servidor da ARTE, I.P, com a _dockerização_, o AccessMonitor passa a poder ser instalado onde quiser. Na sua máquina local, na sua rede local, na sua intranet, a dar apoio ao seu CMS, ... . Desta forma o AccessMonitor ganha graus de liberdade para avaliar ainda mais páginas.
